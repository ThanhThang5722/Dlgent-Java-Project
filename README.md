## GIỚI THIỆU ĐỒ ÁN

-    **Đề tài:** Xây dựng hệ thống BACKEND về trang thương mại điện tử bán giày
-    **Repository BACKEND:** [LẬP TRÌNH JAVA - IS216](https://github.com/ThanhThang5722/Dlgent-Java-Project)
-    **Mô tả:** Đề tài "Xây dựng hệ thống quản lý và đặt phòng khu nghỉ dưỡng" là một đồ án môn học được thực hiện với mục tiêu xây dựng một hệ thống phần mềm hỗ trợ công tác quản lý và đặt phòng tại khu nghỉ dưỡng một cách hiệu quả, hệ thống và dễ sử dụng. Hệ thống được thiết kế bao gồm các chức năng chính như quản lý thông tin phòng, khách hàng, đặt phòng, thanh toán và báo cáo. Trong quá trình triển khai, nhóm đã vận dụng các kiến thức về phân tích, thiết kế và lập trình hệ thống thông tin, kết hợp với kỹ năng làm việc nhóm và sử dụng công cụ phát triển phần mềm để hoàn thiện sản phẩm

## CÔNG NGHỆ VÀ CÔNG CỤ SỬ DỤNG

### Backend Development
- [Java](https://www.java.com/en/) - Ngôn ngữ lập trình chính
- [Spring Boot](https://docs.spring.io/spring-boot/docs/current/reference/htmlsingle/) - Framework phát triển ứng dụng
- [Maven](https://maven.apache.org/) - Công cụ quản lý dự án và dependencies
- [Spring Data JPA](https://spring.io/projects/spring-data-jpa) - Framework truy cập dữ liệu
- [Spring Security](https://spring.io/projects/spring-security) - Framework bảo mật
- [Spring Mail](https://docs.spring.io/spring-framework/docs/current/reference/html/integration.html#mail) - Gửi email
- [Apache POI](https://poi.apache.org/) - Xử lý file Microsoft Office

### Frontend Development
- [Thymeleaf](https://www.thymeleaf.org/) - Template engine
- [Bootstrap 5](https://getbootstrap.com/) - Framework CSS
- [ChartJS](https://www.chartjs.org/) - Thư viện biểu đồ
- [360 Virtual Tour](https://pannellum.org/) - Công nghệ tour ảo 360 độ

### Database & Tools
- [Oracle](https://www.oracle.com/) - Hệ quản trị cơ sở dữ liệu
- [dbForge Studio For Oracle](https://www.devart.com/dbforge/oracle/studio/) - Công cụ quản lý database
- [Visual Studio Code](https://code.visualstudio.com/) - IDE phát triển
- [Ngrok](https://ngrok.com/) - Công cụ tạo tunnel
- [GitHub](https://github.com/) - Quản lý mã nguồn

### Third-party Services
- [Cloudinary](https://cloudinary.com/) - Quản lý và lưu trữ hình ảnh
- [ZaloPay API](https://docs.zalopay.vn/) - Cổng thanh toán
- [Canva](https://www.canva.com/) - Thiết kế đồ họa
